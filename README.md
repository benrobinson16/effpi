# Extended Effpi: verified message-passing programs in Dotty

Effpi is an experimental toolkit for _strongly-typed_ concurrent and
distributed programming in Scala 3, with verification capabilities
based on _type-level model checking_.

**This is an extended version of Effpi, with support for branching and timeout operations. See the paper for details.**

The home page of (the original) Effpi is: <https://alcestes.github.io/effpi>

**Note**: to compile Effpi, JDK 11 is recommended.
